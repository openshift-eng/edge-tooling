# openshift-ci-mcp

MCP server providing read-only access to OpenShift CI data (Sippy, Release Controller, Search.CI)

## Installation

Install via Claude Code's plugin system:

```text
/plugin marketplace add openshift-eng/edge-tooling
/plugin install openshift-ci-mcp
```

## Usage

**The MCP Server is readonly and requires no credentials. It is fully configured by default.**

See the usage data available in the [source README](https://github.com/jeff-roche/openshift-ci-mcp?tab=readme-ov-file#usage)

## Requirements

- **Claude Code:** >= 1.0.0
- **Category:** ci-cd
- **Utilities:** podman
